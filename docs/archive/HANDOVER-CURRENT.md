## ۲. کارهای انجام‌شده در شیفت امروز
۱. **رفع باگ اسکرول صفحه لندینگ:** رفع مشکل شروع صفحه از پایین در ورود به پرتال و اصلاح ریسپانسیو کاشی‌های ورود به حالت ۲ ستونه در موبایل.
۲. **اتصال و همگام‌سازی گیت‌هاب:** اتصال ریموت با توکن دسترسی اختصاصی، کامیت‌ها و پوش خودکار همه تغییرات روی `origin/main`.
۳. **ادغام ۱۳ ویژگی بهینه‌سازی از نسخه مقایسه‌ای:**
   - سیگنال‌های کارتابل مصوبات ریاست و تریاژ خطای پزشکی (`my-work.js`)
   - تسک ابلاغ ماهانه تفویض وظایف شیفت مترون (`role-duties.js`)
   - کارت‌سازی خودکار جدول‌های RPG در موبایل با `data-l` (`resource-page.js`)
   - استایل‌های ریسپانسیو و کارت‌های بدون اسکرول افقی در موبایل (`app.css`)
   - گسترش جستجوی سریع سراسری (`Ctrl + K`) از ۲۰ به ۴۵ مقصد در سامانه (`app.js`)
   - بازآرایی و اصلاح دسته‌بندی ۱۴ صفحه در هاب ماژول‌ها و ثبت نام مسیرها (`PAGE_TITLE_FA`)
   - وضعیت‌های خالی هدایت‌کننده همراه با دکمه اقدام سریع (`loadLegalDuties` و `loadDuties`)
۴. **تست‌ها:** اجرای موفق `npm run smoke-test` (۶/۶)، `npm run test:assistant` (۲۱/۲۱) و `npm run test:assistant-response` (۱۰/۱۰).
۵. **پشتیبان‌گیری گوگل درایو و پاک‌سازی دسکتاپ:** ایجاد سیستم خودکار پشتیبان‌گیری بدون جا گذاشتن فایل‌های اضافه روی دسکتاپ.

## ۳. راهنمای گام‌به‌گام راه‌اندازی در کامپیوتر منزل
هنگامی که به منزل رسیدید و سیستم خود را روشن کردید:

1. **دانلود یا اکسترکت پروژه:**
   فایل زیپ `hospital-accreditation-platform-1405-06-23_10-32.zip` را از همین پوشه گوگل درایو (`G:\My Drive\آنتی گراویتی`) بردارید یا پوشه پروژه را باز کنید.
2. **اجرای برنامه در ترمینال:**
   ```bash
   cd hospital-accreditation-platform-main
   npm install       # (در صورتی که اولین بار است)
   npm start         # سرور روی پورت 3000 اجرا می‌شود
   npm run smoke-test # تست ۶ چک سلامت سامانه
   ```
3. **مشاهده در مرورگر:**
   آدرس زیر را باز کنید:
   `http://localhost:3000/?hospital=dd43b5de-bd17-4245-8dbf-246de3db401d`
