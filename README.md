# پروژه نهایی آتریا — سامانه جامع مدیریت، کیفیت و اعتباربخشی بیمارستان

> **پروژه نهایی آتریا** نسخه‌ی کامل و تست‌شده‌ی سامانه مدیریت کیفیت و اعتباربخشی بیمارستان است. این نسخه شامل **۲,۵۳۵ سند واقعی استخراج‌شده از آرشیو بیمارستانی** است که در این تحویل اضافه شد.

---

## 🎯 چه چیزی در این نسخه اضافه شد؟

| مورد | قبل | بعد |
|---|---|---|
| **اسناد کنترل‌شده** | ۶۰۱ | **۳,۴۳۳** (۵.۷ برابر) |
| **متن واقعی استخراج‌شده** | ~۲ میلیون کاراکتر | **۱۳.۲ میلیون کاراکتر** |
| **میانگین طول متن سند** | ~۱۰۰ کاراکتر | **۳,۸۹۴ کاراکتر** |

**فایل اصلی این بهبود:** `database/seed-md-full.js` — تمام فایل‌های markdown در پوشه‌ی `md/` را می‌خواند، سندهای یکتا را استخراج و در دیتابیس وارد می‌کند (idempotent).

## 📦 نصب و اجرا

سرور روی **http://localhost:3000** اجرا می‌شود.


## 📚 واردکردن آرشیو اسناد (اختیاری)

اگر می‌خواهید **۲,۵۳۵ سند واقعی** وارد کنید:

```bash
# ۱. پوشه‌ی md را کنار پروژه قرار دهید:
#    پروژه نهایی آتریا/
#    md/                          ← این پوشه

# ۲. اجرای seed
npm run seed-md-full
```

یا با مسیر دلخواه:

```bash
MD_DIR=/path/to/md npm run seed-md-full
```

**ویژگی‌ها:**
- ✅ **Idempotent** — اجرای چندباره تغییری ایجاد نمی‌کند
- ✅ **پاکسازی خودکار** — اسناد غیرسندی (فهرست، پرامپت) حذف می‌شوند
- ✅ **شناسایی نوع** — خط‌مشی/روش/دستورالعمل/چک‌لیست/فرم/تصویر
- ✅ **متن کامل** — هر سند متن کامل OCRشده را در `purpose` دارد

## ⚠️ نکات امنیتی مهم

۱. **JWT_SECRET** در `.env` به‌صورت خودکار با یک کلید تصادفی جایگزین شده است. هرگز آن را تغییر ندهید مگر اینکه همه‌ی نشست‌ها باطل شوند.

۲. **require_password** پیش‌فرض خاموش است. قبل از استفاده‌ی واقعی روشن کنید.

۳. **HTTPS** در production اجباری است. `NODE_ENV=production` بدون گواهی SSL باعث خطای CSP می‌شود.

۴. **DATA_DIR** را در سرور روی یک دیسک ماندگار تنظیم کنید.
