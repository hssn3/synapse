# scripts/archive — ابزارهای تاریخی (خارج از جریان اجرا)

## split_backend_monolith.js
ابزار یک‌بارمصرفِ زمانی که بک‌اند یک فایل غول بود و قرار شد به ماژول‌ها شکسته شود.
اکنون بدون مصرف است و requireهایش به فایل‌های دیگر (مثل `../common`) حل نمی‌شود؛
اگر روزی لازم شد باید نسبت به ساختار فعلی به‌روز شود. **از خط فرمان اجرا نکنید.**
